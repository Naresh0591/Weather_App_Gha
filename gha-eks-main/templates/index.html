Deployment Pipeline

1

Checkout & Build

GitHub Actions checks out the repo and builds a Docker image.

2

Security Scan

Trivy scans the image for critical & high vulnerabilities.

3

Push & Notify

Image is pushed to Docker Hub; Slack gets a build notification.

4

Deploy to EKS

The manifest is auto-updated with the new tag and applied to Kubernetes.
